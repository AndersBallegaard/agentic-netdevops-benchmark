# Environment

## Server

The host you are connected to is the management and support services server.

The user on this machine has SSH keys for all devices in the network section.

You are permitted to install any tooling or software required for the task, including software explicitly mentioned and anything you judge necessary.

## Network

All network devices have one preconfigured interface. Treat this as the WAN interface: it is an unsecured network that allows reachability.

All devices use the username vyos and SSH key-based authentication.
