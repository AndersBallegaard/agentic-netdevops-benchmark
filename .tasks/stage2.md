# Stage 2 - Basic Setup

## Prerequisites

- Read ENV.md
- Read WoW.md

## Tasks

- Set hostnames for all devices.
- Set interface descriptions on the WAN interfaces.
- Disable password-based SSH login.
- Set up Prometheus on the server to monitor reachability and device state.

## Verification

- Verify that the hostname and interface descriptions are present in the running configuration.
- Verify that Prometheus receives data.
